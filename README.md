🏥 HealthFind SAEmpowering Community Healthcare AccessHealthFind SA is a streamlined directory designed to bridge the gap between South African citizens and local healthcare facilities. Built with a focus on speed and reliability, it offers real-time clinic discovery and appointment management.💎 Key HighlightsMission: To provide a single source of truth for community health center availability and patient feedback across South Africa.🔍 Precision Search – Find facilities by name, city, or province.📡 Live Status – Instant "Open/Closed" indicators based on real-time operating hours.📅 Patient Portal – Track scheduled, completed, and cancelled bookings in one view.⭐ Community Trust – Integrated review system with star ratings and patient testimonials.🛠 Technical ArchitectureLayerTechnologyPurposeFrontendHTML5 / CSS3Modern, responsive UI with Inter typographyBackendSupabase v2Database, Auth, and Real-time data fetchingServicesGoogle Maps APILocation verification and place detailsIconsInline SVGLightweight, scalable vector graphics📂 System Components1. The Directory EngineThe core of the app utilizes a responsive grid system. Each facility is represented by a "Clinic Card" that displays metadata such as sector status (Public/Private) and facility type.2. Booking LifecycleThe system tracks appointments through three primary states:Scheduled (Blue)Completed (Green)Cancelled (Red)3. Review & Feedback LoopPatients can interact with the directory by submitting reviews.
